# Fofo Auto Box — Android APK

تطبيق Android تجريبي يعتمد على AccessibilityService لمساعدة المستخدم في العثور على عنصر صندوق/مكافأة قابل للنقر داخل تطبيق آخر.

## الاستخدام
1. ثبّت APK.
2. افتح التطبيق.
3. من "تفعيل خدمة الوصول" فعّل Fofo Auto Box.
4. افتح FofoChat.
5. عند ظهور عنصر نصي قابل للنقر يحتوي على كلمات الصندوق/المكافأة، يحاول التطبيق الضغط عليه.

مهم: هذا الإصدار يعتمد على النص/وصف العنصر في واجهة Android. إذا كان الصندوق صورة فقط بلا وصف وصول، فلن يستطيع اكتشافه بهذه الطريقة. لا يتجاوز CAPTCHA أو تسجيل الدخول أو حماية الحساب.

## بناء APK
المشروع يستخدم Android Gradle Plugin 8.6.1 و compileSdk 35.
